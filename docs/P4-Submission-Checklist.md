# SIT313 P4 Submission Checklist

## Project and code

- [ ] Confirm the P3 homepage content and style are retained.
- [ ] Compare the navbar with the original P4 design image in CloudDeakin and adjust spacing/labels if required.
- [ ] In Firebase Console, enable Email/Password Authentication and create a Firestore database.
- [ ] Copy `.env.example` to `.env`; enter Firebase Web App settings; do not commit `.env`.
- [ ] Publish `firestore.rules` to Firestore.
- [ ] Test successful registration, duplicate-email error, invalid email, weak password, mismatched password, successful login, wrong password, and redirect behaviour.
- [ ] Confirm profile details appear in Firestore under `users/{uid}` and no password is saved there.
- [ ] Test at desktop and mobile widths.
- [ ] Create GitLab project **Task P4** with visibility **Internal**.
- [ ] Commit source/resources with meaningful messages; verify `node_modules`, `dist`, and `.env` are not committed.

## Video (required by task sheet)

- [ ] Record a 2–4 minute walkthrough using `Video-Walkthrough-Script.md`.
- [ ] Show the home page and updated navigation.
- [ ] Explain the `Navbar`, `Login`, `Register`, and Firebase configuration files.
- [ ] Demonstrate registration, Firestore profile creation, successful login, and a failed login.
- [ ] Upload to YouTube or Panopto and copy the share link.

## Short report (required by task sheet)

- [ ] Open `Report-Template.md` (or create a Word report from it).
- [ ] Insert fresh screenshots taken from your running application after Firebase setup.
- [ ] Add the real Task P4 GitLab URL.
- [ ] Add the real YouTube/Panopto video URL.
- [ ] Export/submit the report in the format requested by your unit staff.

## Final submission

- [ ] Upload the repository link, report, screenshots/links, and required evidence to OnTrack.
- [ ] Engage with feedback and make changes until the task is marked Complete.
